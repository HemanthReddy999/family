# Our Family Tree — GitHub Pages

Upload `index.html`, `style.css`, `data.js` and `script.js` to a GitHub repository.

Then open **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

## Edit the family

Only `data.js` normally needs editing.

Each person can have:
- `name`
- `gender`
- `spouse`
- `parents`
- `children`
- `birth`
- `notes`

The generation level is calculated automatically from the relationships.
